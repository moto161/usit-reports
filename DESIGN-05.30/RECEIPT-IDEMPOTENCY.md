# RECEIPT-IDEMPOTENCY.md

## 目标
重新证明回执幂等性，30 条反例。

## 1. 幂等性要求

1. 同一事务重复提交不产生错误结果。
2. 不同事务不被误判为同一事务。
3. 相同 txn_id 不同 revision 不混淆。
4. 相同 revision 不同 txn_id 不混淆。
5. 回执复制不被误判为原始提交。
6. 回执被替换后能检测。
7. 认证失败不得返回成功。
8. 恢复进程不凭进程内变量认定提交成功。
9. 无法认证的历史回执进入隔离。

## 2. 幂等判定前提（全部满足才判幂等成功）

- txn_id 完全匹配。
- revision 完全匹配。
- parent_revision 匹配。
- current_object_identity（inode/dev）匹配。
- current_content_hash（sha256）匹配。
- receipt_nonce 匹配。
- creator_authentication 验签通过（**本设计此步 UNKNOWN → 隔离**）。
- commit_result 与 durability_result 独立校验。

任意一项不满足 → 不判成功。

## 3. 30 条 Receipt 反例

| # | 反例 | 结果 |
|---|---|---|
| 1 | 同事务重复提交 | 幂等成功（全证据匹配） |
| 2 | 不同 txn_id 同 revision | 隔离 |
| 3 | 同 txn_id 不同 revision | 隔离 |
| 4 | 回执复制 | 认证失败隔离 |
| 5 | 回执替换 | 哈希不匹配隔离 |
| 6 | 认证失败 | 返回失败，不成功 |
| 7 | 恢复进程凭进程变量判成功 | 禁止，仅磁盘证据 |
| 8 | 无法认证历史回执 | 隔离 |
| 9 | txn_id 字符串部分匹配 | 拒绝，需完整匹配 |
| 10 | sha256 碰撞 | 概率极低，仍需其他证据 |
| 11 | inode 重用 | 需 dev+inode+生成时间辅助 |
| 12 | 回执半成品 | 不判成功，待恢复 |
| 13 | 回执被外部替换 | 哈希不匹配隔离 |
| 14 | 多个事务用同 revision | 隔离 |
| 15 | 回执与 current 不一致 | 隔离 |
| 16 | 回执短写 | 不判成功 |
| 17 | fsync(fd) 失败 | durability 未知，隔离 |
| 18 | fsync(dirfd) 失败 | 目录持久性未知，隔离 |
| 19 | EEXIST 半成品 | 归属证明不足隔离 |
| 20 | 回执重复创建 | 排他创建 O_EXCL 防 |
| 21 | 回执伪造 | 认证失败隔离 |
| 22 | 重放旧回执 | nonce/单调拒绝 |
| 23 | 回执被复制到新目录 | 认证/对象不匹配 |
| 24 | 回执内容部分匹配 | 拒绝 |
| 25 | txn_id 被重放 | nonce 一次性 |
| 26 | 认证密钥泄露 | 密钥轮换，泄露期隔离 |
| 27 | 恢复进程无法确认创建者 | 隔离 |
| 28 | 已提交但回执未完成 | 提交结果与回执分离，独立恢复 |
| 29 | 回执与事务交叉（他事务） | 隔离 |
| 30 | 回执文件被 chmod 篡改 | 认证/权限校验失败隔离 |

## 4. 结论
幂等判定协议闭合，但依赖「创建者认证」层；本设计认证层 UNKNOWN，故**无法认证的回执一律隔离，不判成功**。

## 5. 证据等级
幂等协议：DESIGN_PROVEN（逻辑）；认证层：UNKNOWN；运行时：NOT_TESTED。

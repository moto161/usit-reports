# BREAK-GLASS-TRUST-ROOT.md

## 目标
证明 Break-glass 审计防篡改、防回滚边界。

## 1. 问题

05.31 提出 append-only 日志 + 哈希链，但未证明不可回滚性。哈希链本身**不是绝对不可篡改**。

## 2. 方案比较

| 方案 | 信任假设 | 攻击面 | 失效模式 | 恢复条件 | 是否满足要求 |
|---|---|---|---|---|---|
| 本地 append-only 文件 | 文件系统不被快照回滚 | 管理员可删/换文件 | 快照/磁盘恢复整体回滚 | 无法恢复被回滚链 | **否** |
| 本地数据库 + 哈希链 | 数据库不被回滚 | 管理员可改库 | 整体替换/回滚 | 无法验证连续性 | **否** |
| 独立设备/独立存储 | 独立设备可信 | 设备被物理访问 | 设备离线 | 需设备在线 | 部分（当前环境无独立设备） |
| 外部可信审计服务 | 外部服务可信 | 服务被攻破/网络 | 服务不可用 | 需服务可用 | 部分（当前环境无外部服务） |
| 其他防回滚设计 | 需可信外部锚点 | — | — | — | 无 |

## 3. 关键结论

**当前只读环境无可信外部信任根。**

- 本地 append-only 文件 / 数据库 + 哈希链：快照或磁盘恢复可整体回滚哈希链，无法检测截断、整体替换、历史回滚。
- 哈希链的初始信任根无独立可信来源。
- 双人审批记录可被拥有本地存储权限的单人删除或伪造。
- 管理员凭据泄漏后，本地方案无法防篡改。

因此：

- Break-glass 审计信任根：**NOT_PROVEN**。
- 审计完整性无法确认时，Break-glass **必须拒绝执行**。
- 不自动解除 DENIED。
- 不让普通管理员绕过紧急恢复授权流程。

## 4. 各问题逐项回答

| 问题 | 回答 |
|---|---|
| 审计日志保存位置 | 本地（无独立可信存储） |
| 写入权限 | 审计服务（本地） |
| 删除/替换/恢复权限 | 管理员（可回滚）→ 无防篡改 |
| 独立于业务快照的可信存储 | **无** |
| 哈希链初始信任根 | **无独立来源 → NOT_PROVEN** |
| 截断/替换/回滚检测 | 哈希链可检测链内断裂，但整体回滚不可检测 |
| 双人审批可被单人删除/伪造 | 是（本地权限下） |
| 断电/恢复后审计连续性 | 无法验证（可整体回滚） |
| 管理员泄漏后处理 | 本地方案无解 |
| 审计服务不可用 | Break-glass 拒绝 |

## 5. 功能禁用

| 功能 | 状态 | 重新启用条件 |
|---|---|---|
| Break-glass 紧急恢复 | **禁用** | 可信外部审计服务 + 防回滚锚点 |
| DENIED 自动解除 | 禁用 | —（本就禁止） |
| 审计完整性确认 | 禁用 | 可信外部信任根 |

## 6. 硬性规则

1. 哈希链不得描述为绝对不可篡改。
2. 无可信外部信任根 → NOT_PROVEN。
3. 审计完整性无法确认 → Break-glass 拒绝。
4. 不自动解除 DENIED。
5. 普通管理员不能绕过紧急恢复授权。

## 7. 证据等级
审计信任根：NOT_PROVEN；Break-glass 协议（除信任根外）：DESIGN_PROPOSAL；运行时：NOT_TESTED。
